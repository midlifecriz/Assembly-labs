Программа вычисляет выражение ac/b + db/e - c^2/(a*d), результат помещается в переменную "result".
Возможны следующие результаты выполнения программы:
• Вычисления выполнены корректно, результат помещен в зарезервированную область памяти, код возврата программы равен 0.
• В процессе вычислений произошла исключительная ситуация, результат не помещен в зарезервированную область памяти, код возврата программы равен соответствующему коду ошибки.
