Лабораторные работы, написанные в рамках курса Ассемблера (NASM x84-64).
В работах затрагиваются следующие темы:
1) Целочисленная арифметика
2) Арифметика с плавающей точкой
3) Сортировка прямоугольной матрицы сортировка Шелла
4) Обработка строк
5) Работа с файлами
6) Вызов функций языка C из ассемблерной программы
